# 교실 도구함

교사가 수업용 웹 프로그램을 모아두는 허브입니다. 교실 타이머, PDF 글자 수 세기, 웹주소 QR 만들기, 나의 일기장, 개인정보 점검 도구를 허브 안에서 실행할 수 있습니다.

## 실행

**`dist/index.html`을 Chrome 또는 Edge로 여세요.** 홈의 **일기장** 카드를 누른 뒤 처음 한 번 **일기 폴더 선택하기**에서 `classroom-hub/data` 폴더를 선택하면 됩니다. 기존 `diary.sqlite`가 있으면 기록을 읽고, 없으면 그 폴더에 새로 만듭니다. 작성·열람·수정·삭제는 허브 화면에서 바로 할 수 있습니다. 브라우저가 폴더 권한을 다시 묻는 경우 허용해 주세요.

폴더 선택 기능이 없는 브라우저에서는 **`교실도구함 열기.cmd`**를 더블클릭하는 기존 방법을 계속 쓸 수 있습니다. 이 방법만 Node.js 22.13 이상이 필요하며, 실행 창은 일기장을 쓰는 동안 열어두세요. 기존 `일기장 시작.cmd`는 일기장 화면으로 바로 엽니다.

일기 데이터베이스 파일은 **`data/diary.sqlite`**입니다. HTML 파일로 직접 열 때는 브라우저가 허용한 폴더의 SQLite 파일을 읽고 다시 씁니다. 같은 데이터베이스를 로컬 서버 방식과 여러 브라우저 창에서 동시에 편집하지 마세요. 파일을 복사해 백업할 수 있습니다. 로컬 서버 방식에서는 이 컴퓨터의 `127.0.0.1`만 사용하며 일기 파일을 정적 파일로 공개하지 않습니다.

## 사용

- **교실 타이머:** 5·10·15·25분 빠른 설정, 직접 설정, 시작·일시 정지·초기화·1분 추가, 전체 화면을 지원합니다. 탭이 뒤에 있어도 실제 종료 시각을 기준으로 남은 시간을 계산합니다.
- **PDF 글자 수 세기:** 컴퓨터의 PDF를 선택하거나 화면에 놓으면 텍스트를 추출해 공백 포함·제외 글자 수와 페이지 수를 보여줍니다. 한글 결합 문자와 이모지는 보이는 한 글자 단위로 셉니다. 파일과 결과는 브라우저 메모리에서만 처리하며, 서버 업로드와 결과 저장을 하지 않습니다. 스캔 이미지, 암호화 PDF, 텍스트로 추출되지 않는 부분은 셀 수 없습니다. 파일 크기 상한은 100MB입니다.
- **웹주소 QR 만들기:** `http://` 또는 `https://`로 시작하는 웹주소를 입력하고 QR을 만든 뒤 PNG로 저장합니다. 입력 주소는 브라우저에서만 처리하고 저장하거나 서버로 보내지 않습니다. QR에 넣은 주소는 이미지 생성 후 바꿀 수 없으므로 학생에게 보여주기 전에 휴대전화로 스캔해 확인하세요.
- **나의 일기장:** 날짜·제목·내용으로 일기를 작성하고 지난 기록을 열어 수정·삭제할 수 있습니다. 기록은 `data/diary.sqlite`에 저장됩니다. 별도의 클라우드 업로드나 계정 연동은 없습니다. 같은 컴퓨터 계정으로 이 파일에 접근할 수 있는 사람은 일기 내용을 볼 수 있으므로 공용 PC에서는 사용에 유의하세요.
- **개인정보 점검:** PDF 또는 `.xlsx` 파일을 선택하면 브라우저 안에서 주민등록번호, 전화번호, 이메일, 학번 표시가 붙은 번호, 이름 표시가 붙은 이름을 찾아 가립니다. 엑셀은 `이름`, `학번`, `전화번호` 등 열 제목 아래의 값도 가립니다. `가린 파일 다운로드`를 누르면 원본과 같은 확장자의 새 파일이 저장됩니다. 결과 PDF는 텍스트로 새로 구성한 이미지 PDF라 검색·복사가 어렵고, 엑셀은 값만 담은 새 파일입니다. 원본 서식·이미지·수식·메타데이터는 결과에서 제외됩니다. PDF 이미지와 손글씨에는 OCR을 적용하지 않습니다. 오래된 `.xls`는 엑셀에서 `.xlsx`로 다시 저장해 주세요. 최대 파일 크기는 30MB입니다. 파일과 결과는 브라우저 메모리에서만 다루며 서버로 보내거나 자동 저장하지 않습니다. 자동 탐지는 누락될 수 있으니 결과를 직접 검토한 뒤 사용하세요.
- **도구 모음:** 완성된 프로그램은 허브 내부 화면으로 열립니다. `프로그램 계획 추가`에서 앞으로 만들 도구의 이름과 설명을 준비 중 카드로 적어둘 수 있습니다. 계획은 수정·삭제할 수 있습니다.

준비 중 카드의 정보는 해당 브라우저의 `localStorage`에만 저장됩니다. 파일로 연 페이지의 저장을 막는 브라우저에서는 카드가 창을 닫을 때 사라질 수 있으며 화면에 안내가 나타납니다. 카드를 추가하는 것만으로 프로그램 기능이 생성되지는 않습니다. 실제 기능을 만들 때 허브의 화면과 프로그램 목록에 연결합니다. 다른 기기와 동기화되지 않으며 브라우저 데이터를 지우면 준비 중 카드가 사라집니다. 학생 개인정보를 입력하지 않는 사용을 전제로 합니다.

## 파일

- `dist/index.html`: 화면 구조
- `dist/styles.css`: `DESIGN (1).md`를 반영한 스타일
- `dist/app.js`: 허브 카드와 내부 화면 이동
- `dist/tools/catalog.js`: 허브에 통합된 프로그램 목록
- `dist/tools/timer.js`: 교실 타이머 동작
- `dist/tools/pdf-counter.js`, `dist/tools/text-count.js`, `dist/tools/embedded-pdf-data.js`: PDF 선택·텍스트 추출·글자 수 계산
- `dist/tools/qr-maker.js`: 웹주소 확인, QR 그리기, PNG 저장
- `dist/tools/diary.js`: 일기 작성·조회·수정·삭제 화면
- `dist/tools/diary-folder-store.js`, `dist/vendor/sqljs/`: 브라우저에서 폴더를 선택해 SQLite 파일을 직접 읽고 쓰는 코드와 sql.js 1.15.0 라이브러리. 라이선스는 해당 폴더의 `LICENSE`에 있습니다.
- `dist/tools/privacy-*.js`: 개인정보 탐지, 새 PDF·엑셀 생성, 화면 동작
- `server.cjs`: 컴퓨터 안에서만 실행되는 정적 파일 서버와 일기 저장 API
- `data/diary.sqlite`: 로컬 SQLite 일기 데이터베이스
- `dist/vendor/qrcode/`: QR 생성용 qrcode-generator 2.0.4. MIT 라이선스는 해당 폴더의 `LICENSE`에 있습니다.
- `dist/vendor/pdfjs/`: 앱에 포함한 Mozilla PDF.js 6.2.108 라이브러리, 문자 맵과 글꼴. HTML에서 직접 열 수 있도록 PDF.js의 작업 코드를 같은 페이지에서 실행하고 문자 맵·글꼴 데이터를 포함했습니다. 라이선스는 해당 폴더의 `LICENSE`와 글꼴 하위 폴더의 라이선스 파일을 확인하세요.
- `dist/vendor/jszip/`, `dist/vendor/xml-js/`, `dist/vendor/pdf-lib/`: 엑셀 파일 읽기·쓰기와 새 PDF 생성에 쓰는 로컬 스크립트. 라이선스는 각 폴더에 있습니다.

## 다음 프로그램을 허브에 통합하는 방법

공개 저장소에는 실제 일기 데이터베이스와 사용자 문서를 포함하지 않습니다. 보안 검토 범위와 사용상 한계는 [SECURITY.md](SECURITY.md)를 참고하세요. 개발 테스트는 Node.js와 pnpm을 설치한 뒤 `pnpm install --frozen-lockfile`, `pnpm test`로 실행합니다. 일반 사용은 설치 없이 `dist/index.html`로 시작할 수 있습니다.

1. `dist/index.html`의 `<main>` 안에 `id="my-tool-view"`와 `data-tool-view`가 있는 새 `<section>`을 만듭니다. 처음에는 `hidden`을 붙이고 홈으로 돌아가는 `href="#home"` 링크를 둡니다.
2. `dist/tools/my-tool.js`에 기능을 작성하고 `index.html`에서 `<script src="./tools/my-tool.js" defer></script>`로 연결합니다. 기존 타이머를 건드리지 않고 독립적으로 만듭니다.
3. `dist/tools/catalog.js` 목록에 `{ id: 'my-tool', name: '도구 이름', description: '설명', viewId: 'my-tool-view', icon: '✳', category: '수업 도구' }`를 추가합니다. 그러면 홈 카드가 생성되고 `#my-tool` 주소로 허브 내부 화면이 열립니다.
4. 로컬 서버 미리보기를 사용할 경우 `server.cjs`의 허용 파일 목록에 `/tools/my-tool.js`를 추가합니다. 정적 호스팅은 파일을 그대로 올리면 됩니다.

준비 중 카드로 적어둔 프로그램을 구현했다면, 내부 프로그램 카드가 나타난 것을 확인한 뒤 기존 준비 중 카드를 삭제하면 됩니다.

기존 버전에서 링크 카드를 저장했다면 새 버전은 이름과 설명을 준비 중 계획으로 가져옵니다. 이전 웹 주소는 새 화면으로 자동 변환할 수 없어 사용하지 않습니다.

디자인 문서의 색상, 검은 1px 윤곽선, 둥근 컴포넌트, 대형 제목과 리본·스티커 표현을 반영했습니다. 원본 전용 폰트가 제공되지 않아 시스템 한글 글꼴을 사용합니다. 타이머 숫자는 교실 프로젝터에서 읽기 쉽도록 디자인 문서의 극단적인 압축 행간 대신 독립된 큰 숫자로 표시합니다.
